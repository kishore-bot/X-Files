| BUILD-02 · Medium | GitHub manual release input enters inline shell parsing before validation in a repo-write workflow. [GitHub secure use](https://docs.github.com/en/actions/reference/security/secure-use) |
| SUPPLY-01 · Medium risk | Separate FFmpeg 7.1.2 and pinned Rust bridge need ABI and advisory review even when Gradle and Cargo lockfiles are current. [Script](../../scripts/build-ffmpeg.sh#L11) | Inventory the packaged binary versions and compiled decoders. Check advisories, artifact hash and licensing notices against exact sources. [FFmpeg security](https://ffmpeg.org/security.html) |

Android stores private caches and uses SAF for local files, with backup disabled and a private FileProvider. Verify unlinked-folder behavior, stale derived text and Android temporary grant lifecycle. Firebase overlays set telemetry defaults off. Feedback can persist until reconnect if queued. Define retention for reply addresses and any cached sensitive data. [Main manifest](../../androidApp/src/main/AndroidManifest.xml) · [SAF](https://developer.android.com/training/data-storage/shared/documents-files) · [Offline persistence](https://firebase.google.com/docs/firestore/manage-data/enable-offline)

Desktop MCP uses stdio and canonicalized explicit roots. Treat check-to-use consistency under concurrent filesystem changes as a risk pending verification. Prefer descriptor-relative ownership where available. Test permission failures, cancellation and partial output. Native format limits should bound archive size, recursion, images, allocation, output and JNI buffer ranges across Android and desktop. Test with owned synthetic fixtures. [Desktop roots](../../engine/crates/xfiles-mcp/src/sandbox.rs#L39) · [Archive](../../engine/crates/document-parsers/src/archive_index.rs) · [JNI](../../ffmpeg/rust/src/bridge.rs)

Excluded private credentials and overlays do not establish clean Git history or deployed cloud policy. Run dependency verification and advisory checks against the Gradle resolution, both Rust lockfiles, vendored binaries and Python requirements after approval. Runtime privacy, detailed parser unsafe review and release signing verification are pending.
