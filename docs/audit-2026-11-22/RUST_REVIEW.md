# Rust and native boundaries

The engine workspace has common models, parsers, search, tidy, glance, imaging, UniFFI façade, Fily inference and host-only MCP. The Media3 audio JNI shim uses its own Cargo manifest and lock. Rust owns parser and native lifecycles. Kotlin owns Android provider integration, speech, UI and domain-facing state. |---|---|
| UniFFI | OxiKT generates Kotlin in `com.xfiles.engine.ffi` from the compiled library. Verify owned versus borrowed FD semantics along Kotlin acquisition, Rust adoption and exactly-once disposal. Keep generated types in the adapter. Profile batched DTO conversion, copied strings and pixels before considering a borrowed interface. ## Fily generation and alternatives

The lock binds llama-cpp-2 and its sys crate to 0.1.161 and UniFFI to 0.32.0. The Android native worker uses a 4096-token context, snapshots the stable prefix with sequence-state save/load, and tries to reuse the common prefix before decoding new tokens. Rust supplies grammar-constrained greedy sampling with Kotlin-generated GBNF. Exact vendored llama.cpp commit provenance and LFM2 compatibility for each packaged GGUF need artifact verification. [Inference manifest](../../engine/crates/fily-inference/Cargo.toml#L8) · [Context and KV](../../engine/crates/fily-inference/src/android.rs#L134) · [Sampler](../../engine/crates/fily-inference/src/android.rs#L257)

Keep the default CPU release. Before enabling OpenCL, verify packaged dependencies, a launch on a driver-less target, and offload and recovery on compatible Adreno. Rust can fall back to CPU during load. Propagate actual backend status before attempting another accelerator or inferring speed from a flag. [OpenCL flag](../../documentEngine/build.gradle.kts#L35) · [Feature map](https://docs.rs/crate/llama-cpp-2/0.1.161/features)

A production move to pure Rust requires a demonstrated matrix of supported LFM2 weights, exact Q4 GGUF, grammar, KV state and Android phone GPU. Candle, mistral.rs and Burn remain evaluation candidates. This audit found insufficient evidence to replace the existing Rust-orchestrated llama.cpp path.
