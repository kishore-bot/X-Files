# Xfiles for iOS

Open `Xfiles.xcodeproj` in Xcode on macOS and select the shared **Xfiles** scheme. Select an iPhone or iPad simulator running iOS 17 or later. For a physical device, set a development team in **Signing & Capabilities** and use a bundle identifier available to that team.

Use **Import files** to select one or more documents in Files. Xfiles keeps its own copy and uses the system's previews. PDF, text, and supported audio and video resume from their last saved position. Quick Look previews depend on the formats available on the device.

See the [iOS architecture and delivery plan](../docs/IOS_ARCHITECTURE.md) for the first delivery, validation checklist, and scope for Android feature parity.
