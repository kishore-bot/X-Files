# Kotlin and KMP opportunities

Target the pinned Kotlin 2.4.21. The examples describe intended application behavior for an approved follow-up. [Catalog](../../gradle/libs.versions.toml) · [Language status](https://kotlinlang.org/docs/whatsnew24.html)

| Technique | Concrete use and decision | Cost and benefit |
|---|---|---|
| Structured concurrency and scope ownership | Use a child scope for the reader session and give each render a generation. Reset invalidates it. [Page use case](../../feature/reader/src/main/kotlin/com/xfiles/feature/reader/domain/PdfPagesUseCase.kt#L26) | Medium. Prevents stale images and teardown races. |
| SupervisorJob | Supervise independent folder children once each reports retryable or permanent failure. Use a regular parent for required steps of an individual export. | Medium. Keeps one provider error from cancelling other sources. |
| Flow and backpressure | Debounce typing and use latest-only search. Conflate progress, preserve ordered install/export outcomes, and acknowledge required navigation. | Low to medium. Less repeated work and deterministic results. |
| StateFlow and SharedFlow | Publish one immutable model operation state with generation and phase. Use buffered SharedFlow only for expendable messages. [Installer](../../feature/assistant/src/main/kotlin/com/xfiles/feature/assistant/AndroidModelDownloads.kt#L119) | Low. Keeps progress and results consistent after recreation. |
| Channels and actors | Keep Rust as the context owner. Consider a bounded Channel only if accepted Kotlin work needs a queue. | Medium. Adopt only with clear ordering and backpressure requirements. |
| Mutex and Semaphore | Enforce one owner across install suspension. Cap OCR concurrency until ML Kit Task completion. | Medium. Explicit memory bounds. [Dispatcher semantics](https://kotlinlang.org/api/kotlinx.coroutines/kotlinx-coroutines-core/kotlinx.coroutines/-coroutine-dispatcher/limited-parallelism.html) |
| Atomic operations and AtomicFU | Rust already has an atomic cancel flag. Use Kotlin Mutex for compound state. Consider AtomicFU for a measured cross-platform single-field hot path. | Defer dependency. [AtomicFU](https://github.com/Kotlin/kotlinx-atomicfu) |
| Contracts | Prefer explicit resource ownership and sealed outcomes. Kotlin contracts require opt-in and cannot make an FFI handle safe. | Defer until a pure function needs a specific smart cast. [Contracts API](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.contracts/contract.html) |
| Inline/reified and extensions | Reuse proven equivalent native conversion and exception translations. Keep actual Android and ABI types visible. | Low. Reduces conversion drift. [Reader mapping](../../documentEngine/src/androidMain/kotlin/com/xfiles/documentengine/StructuredDocumentReader.kt#L127) |
| Context parameters | Stable core language support. Consider narrow diagnostic context for pure format operations. Context arguments and callable references have separate status. | Defer. Constructor injection currently makes ownership clearer. [Kotlin 2.4](https://kotlinlang.org/docs/whatsnew24.html) |
| Delegated properties and backing fields | Use lazy properties for immutable metadata. Explicitly own file descriptors, bitmaps and model handles. | Low. Small state cleanup benefit. |
| Sealed hierarchies and value classes | Represent retry, unsupported and success with sealed results. Wrap document revision or operation identity internally and map to existing ABI primitive fields. | Low to medium. Exhaustive handling and fewer mixed keys. Measure boxing on hot collections. |
| Type-safe builders, functional composition | Share the stages of export through an immutable validated request. Compose pure ranking and validation functions. Defer a DSL until several workflows use it. | Medium. Easier tests around cancellation and commit. |
| Result and Either-style errors, immutable state | Keep cancellation as control flow. Use Result for simple failures and domain-relevant types where retry behavior differs. | Low. Addresses empty-success conversion in search. [Index](../../core/documents/src/main/kotlin/com/xfiles/core/documents/LibrarySearchRepository.kt#L70) |
| Serialization | Add schema/default regression fixtures for reader position, bookmarks and settings. Keep GBNF and ABI DTO limits explicit. | Medium. Safer upgrades. [Build](../../sharedLogic/build.gradle.kts) |
| Expect/actual and DI | Keep Hilt on Android and inject narrow file, speech and clock ports. Adopt expect/actual where iOS requires a small platform declaration. Expect/actual classes are Beta. | Medium once iOS is scoped. [KMP platform declarations](https://kotlinlang.org/docs/multiplatform/multiplatform-expect-actual.html) |
| Compiler and build | Certify the toolchain and configuration-cache matrix before introducing build conventions or experimental flags. | Medium. Improves reproducibility. [Compatibility](DOCUMENTATION_REFERENCES.md) |
