# Product opportunities

| Priority | User problem and proposal | Components and dependencies | Cost, performance and privacy |
|---|---|---|---|
| Essential P0 | Ambiguous local voice setup. Show installed local input and output readiness and offer pack setup when needed. | Kotlin assistant UI, Android speech adapters and shared preference. Keep the existing Rust ABI. | Medium. Check readiness off the answer path. Avoid network-capable speech by policy. [Speech](../../feature/assistant/src/main/kotlin/com/xfiles/feature/assistant/SpeechRecognition.kt#L60) |
| Essential P1 | Unclear repair after model or export failures. Show honest retry, progress and partial-output cleanup. | Kotlin installer and export ViewModels, SAF adapter and typed native outcome. Existing dependencies. | Medium. Bounded staging and cleanup. Avoid storing payload diagnostics. [Install](../../feature/assistant/src/main/kotlin/com/xfiles/feature/assistant/AndroidModelDownloads.kt#L119) |
| Optional P4 | Search hits lack precise reader context. Open a result at the actual PDF page or book position, then return to prior place. | Kotlin library, reader and Navigation 3, reused Rust hit snippet and offset, shared location model. | Medium. Fetch context only on selection. Respect source revision and linked grants. [Rust query](../../engine/crates/document-search/src/index.rs#L364) |
| Optional P4 | Long scanned documents appear idle. Offer partial search hits, accurate progress and stop. | Kotlin reader state and bounded ML Kit adapter, shared position contract and existing native text layer. | Medium. Measure time to first result, preserve mixture of scanned and searchable pages, keep ephemeral OCR text private. [PDF search](../../core/documents/src/main/kotlin/com/xfiles/core/documents/AndroidPdfDocument.kt#L317) |
| Optional P4 | Glass styling and motion can obscure actions. Add high contrast and reduced-motion preferences. | Kotlin design system, accessibility semantics and saved appearance. No Rust change. | Easy to medium. Test contrast, frame timing, large font and TalkBack on phones and tablets. [Surfaces](../../core/designsystem/src/main/kotlin/com/xfiles/design/Surfaces.kt#L35) |
| Optional P4 | Desktop batch outputs are hard to predict. Report exact output plan and partial outcome. | Rust MCP tools, existing staged publisher and rmcp. Wire Kotlin only if there is an Android caller. | Medium. Cap previews and confirm root access. [Output owner](../../engine/crates/xfiles-mcp/src/output.rs#L20) |
| Later P4 | iOS users need native reading. Start with one read-only Swift file picker and format. | Add iOS target, Swift shell and OxiKT/UniFFI linkage proof. Keep Android-native UI. | Hard. Certify framework size, sandbox rights, memory, cold start and simplest parity first. [KMP structure](https://kotlinlang.org/docs/multiplatform/multiplatform-project-recommended-structure.html) |
