# Official documentation and version ledger

**Research date · 22 November 2026**

| Topic | Repository and official evidence | Recommended decision |
|---|---|---|
| Kotlin and Gradle · TOOL-01 | Kotlin/KGP 2.4.21 and Gradle 9.9.2. JetBrains’ fully supported row for this KGP ends at Gradle 9.7.0 and AGP 9.3.1. Gradle 9.9.2 is a stable patch. [Kotlin releases](https://kotlinlang.org/docs/releases.html) · [KGP matrix](https://kotlinlang.org/docs/gradle-configure-project.html) · [Gradle](https://docs.gradle.org/9.9.2/release-notes.html) | Certify the whole tuple before upgrading. |
| AGP | Catalog declares 9.5.2. The AGP 9.5 line documents API 37, minimum Gradle 9.6.0 and JDK 17. Verify the pinned patch and SDK minor revision with a clean build. [AGP 9.5](https://developer.android.com/build/releases/agp-9-5-0-release-notes) | Evaluate SDK and DSL implications if narrowing the toolchain. |
| Android KMP | Built-in Kotlin for app and Android libraries. KMP library uses the nested Android DSL. Its single variant omits Android-specific native builds, and Java, resources and host/device tests are opt-in. AGP 10 removes the built-in Kotlin opt-out and legacy KMP Android plugin combination. [KMP plugin](https://developer.android.com/kotlin/multiplatform/plugin) · [AGP 9 migration](https://kotlinlang.org/docs/multiplatform/multiplatform-project-agp-9-migration.html) · [Built-in Kotlin](https://developer.android.com/build/migrate-to-built-in-kotlin) | Keep external Cargo wiring and native Android UI. |
| KMP structure | 2026 guidance separates app shells, shared logic and optional shared UI. [JetBrains May release](https://blog.jetbrains.com/kotlin/2026/05/new-kmp-default-structure/) · [Structure](https://kotlinlang.org/docs/multiplatform/multiplatform-project-recommended-structure.html) | Add an iOS umbrella when its Swift shell consumes multiple modules. |
| Rust and NDK | Rust 1.100.0 and NDK r29 pinned. The current Rust stable release checked is 1.100.0. NDK r30 is upstream LTS. [Rust release](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/) · [NDK](https://developer.android.com/ndk/downloads) | Reproduce current build before testing newer NDK. |
| Bridge | OxiKT 1.4.0 expects UniFFI 0.32.0. The upstream guide lists AGP 9.3.1 as tested. [OxiKT](https://github.com/UbiqueInnovation/oxikt) · [UniFFI change history](https://github.com/mozilla/uniffi-rs/blob/main/CHANGELOG.md) · [Gobley releases](https://github.com/gobley/gobley/releases) | Keep bridge and regenerate against matching libraries. Assess binding/API changes before any switch. |
| Media and FFmpeg | Media3 1.11.1 stable, 1.12.0 beta. FFmpeg 7.1.2 local. Latest patch in 7.1 branch is 7.1.5, current branch release is 9.1. [Media3](https://developer.android.com/jetpack/androidx/releases/media3) · [FFmpeg releases](https://ffmpeg.org/download.html) · [Security](https://ffmpeg.org/security.html) · [Distribution checklist](https://ffmpeg.org/legal.html) | Keep vendored Java and Media3 APIs in step. Evaluate same-branch FFmpeg patch and distribution evidence before major upgrade. |
| Native packages | NDK r28+ defaults to 16 KB-aligned binaries. Verification includes every packaged library and APK archive alignment plus device runtime. [16 KB guidance](https://developer.android.com/guide/practices/page-sizes) | Check both ABIs and app/decoder/OpenCL behavior on 16 KB. |
| Gradle optimization | Release uses `--no-configuration-cache`. Isolated Projects is incubating. FFmpeg uses a project copy in a task closure and filesystem-conditioned task wiring. [Cache requirements](https://docs.gradle.org/current/userguide/configuration_cache_requirements.html) · [Isolated Projects](https://docs.gradle.org/current/userguide/isolated_projects.html) · [FFmpeg Gradle](../../ffmpeg/build.gradle.kts#L54) | Test typed inputs, then audit OxiKT and connected profile tasks individually. |
| R8 and profiles | Release optimization is enabled, automatic profile generation is off. Public tree lacks the documented generated profile. [R8](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization) · [Baseline Profiles](https://developer.android.com/topic/performance/baselineprofiles/overview) | Certify generated profile, keep rules, reflection and runtime in release. |

Source opt-outs include variant filtering, optional Firebase and OpenCL, manual baseline profile generation, the explicit CI cache switch and optional ignored overlays. No public legacy Kotlin or DSL opt-out was found. Explicit deprecated or unstable use occurs in the TTS compatibility callback, About compatibility block, Media3 unstable APIs, Compose/benchmark opt-ins and coroutine experimentation. A compiler and lint run is needed for full transitive deprecation coverage.
